# Icon assets

## Font Awesome Free 7.3.1

The `fontawesome/` directory holds the complete Font Awesome
Free SVG icon set (solid, regular, brands), downloaded from
the official `@fortawesome/fontawesome-free` package
(https://fontawesome.com).

License: the icons are CC BY 4.0 (see
`fontawesome/LICENSE.txt`); attribution: "Icons: Font
Awesome Free 7.3.1 by @fontawesome — https://fontawesome.com".

Phase H embeds a curated subset of these paths into the
editor's icon system; the full set stays here as the source
of truth for picking more icons.
